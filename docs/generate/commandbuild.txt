@title(Build)
@shorttitle(Build)

@section(1 SecFirst Description)

This command just calls lazbuild to perform the build, if you want to compile the project manually, we recommend using the lazbuild tool or the fpc compiler itself for that.

The reason behind the existence of this command along with pasc is only for the implementation of the watch command.

Example:
@longCode(
  pasc build HelloWorld.lpi
)

Without an argument it builds the project in the current folder (the .lpi, the .lpk of a package or the .lpr). A folder builds the project found in it. At the root of a @link(workspace workspace) it builds every member, packages before the members that require them:

@longCode(
  pasc build
  pasc build apps/cli
)

The options @html(<code>--debug</code>) and @html(<code>--release</code>) choose the build mode.
