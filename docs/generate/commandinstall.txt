@section(1 SecFirst Description)

@bold(Deprecated.) Up to version 1.2.1 this command copied pasc to a .pasc folder in the user's home and added it to the PATH. That was unreliable, so it no longer changes anything: it shows how to install pasc with a package manager, manually or from the sources (see @link(install Install)), and, when it finds an install made by a previous version, the steps to remove it: the ~/.pasc folder and its PATH entry in ~/.profile, /etc/paths or the Windows user PATH.

It exits with code 1, since nothing is installed.

Example:
@longCode(
  pasc install
)
