@title(Install)
@shorttitle(Install)

Pasc is a standalone executable. Release binaries are published for Linux and Windows (x86_64); on other platforms, such as macOS, build it from the sources.

@section(3 SecFirst With mise (recommended))

@html(<a href="https://mise.jdx.dev">mise</a>) installs pasc from the GitHub releases, and also upgrades and uninstalls it:

@longCode(
  mise use -g github:laprado/pasc
  mise upgrade github:laprado/pasc
)

@section(3 SecSecond Manual installation)

From the @html(<a href="https://github.com/laprado/pasc/releases/latest">latest release</a>) download the zip for your platform and @code(pasc_checksums.txt), check the zip against it and extract it to a folder in your PATH. On Linux:

@longCode(
  curl -fsSLO https://github.com/laprado/pasc/releases/latest/download/pasc-linux-amd64.zip
  curl -fsSLO https://github.com/laprado/pasc/releases/latest/download/pasc_checksums.txt
  sha256sum -c --ignore-missing pasc_checksums.txt
  unzip pasc-linux-amd64.zip -d ~/.local/bin
)

On Windows, the README has the same steps for PowerShell. The checksums file is published for the releases after 1.2.1.

@section(3 SecThird Build it from the sources)

You need @bold(FPC) 3.2.2, @bold(Lazarus) 4.x (for lazbuild), @html(<a href="https://github.com/HashLoad/boss">boss</a>) 3.x and git:

@longCode(
  git clone https://github.com/laprado/pasc.git
  cd pasc
  boss install
  lazbuild apps/pasc/pasc.lpi --build-mode=Release
)

The executable is @code(apps/pasc/pasc) (pasc.exe on Windows). Copy it to a folder in your PATH.

@section(3 SecFourth Upgrading from pasc install)

Versions up to 1.2.1 installed themselves with @code(pasc install), copying pasc to ~/.pasc and changing the PATH. That command is deprecated, see @link(commandinstall Install Command): it shows how to remove an old install.

@section(1 SecFifth Test pasc)

To see if pasc is working type the following:

@longCode(
  pasc help new
)

It shows the version and the usage of the new command.
